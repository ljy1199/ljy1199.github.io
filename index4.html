球柱法检影要点

  1. 工作距离决定人工近视:距离 d 处检影,相当于被检眼戴了 −1/d 的镜片。50cm→−2.00D,67cm→−1.50D,100cm→−1.00D。
  2. 中和公式:某子午线 屈光不正度数 = 中和镜片 + 人工近视,即该方向所需镜片 C = P + 1/d。反过来说,纯检影度数 = 粗检影度数 + 人工近视。
  3. 光带与被检子午线垂直。旋转光带时,被检子午线随之改变。检影镜光带横跨整个眼球(比瞳孔内的影动光带宽),瞳孔内外都能看到,便于直接比对两者的方向与角度:对准主子午线时两条光带平行;未对准时影动光带会偏斜成一个夹角,即斜向影动——这正是判断散光轴的依据。
  4. 影动性质——看两条光带的移动关系:检影镜光带沿被检子午线方向来回扫动,瞳孔内的影动光带与之同向移动 = 顺动(剩余正屈光力,矫正不足,需加正镜片);反向移动 = 逆动(剩余负屈光力,矫正过度,需加负镜片);光带照常扫动而影动光带停住不动、瞳孔被均匀照亮 = 中和。
  5. 影动速度与光带宽度:离中和越远,影动越慢、摆动幅度越大、光带越窄;越接近中和,影动越快、幅度越小、光带越宽("变宽、变亮、变快"是接近中和的体征)。所以看到频率变快、幅度变小、光带变宽,就说明快中和了,此时镜片要小步调(0.25D 一档);一旦影动停止不动、光带铺满瞳孔,即为中和点。
  6. 球柱法顺序:① 先用球镜中和一条主子午线(通常选所需镜片较少、即屈光力较低的那条),球镜只在该方向上"中和";② 把柱镜轴向放到这条已被球镜中和的方向上——柱镜在它的轴向上没有屈光度,因此不会破坏刚刚中和好的方向,而它在垂直方向上有全部屈光度,正好用来中和第二条子午线;③ 逐步加柱镜,把第二条子午线的影动也调到中和。轴向若放错,两条主子午线之间会残留屈光力(出现斜向影动),第二条子午线永远无法中和。只要球镜与柱镜都加对,再把检影镜光带旋转一整圈,每一个方向都会保持中和 —— 这就是本页的通关条件(可用右侧「全方向验证」让光带自动扫一圈核对)。
